# RepeaterTastic KISS modem build targets.
#
# Format (pipe-separated, whitespace around fields ignored):
#   pio env | friendly name | MCU | radio | flash format [| options]
#
# options: core=pioarduino  build with a separate PlatformIO core dir (ESP32-C6 envs use the
#                           pioarduino espressif32 fork, which cannot share ~/.platformio with
#                           platformio/espressif32@6.11.0)
#
# flash format: esp32  -> <env>-factory.bin (esptool, 0x0) + <env>-app.bin (0x10000)
#               nrf52  -> <env>.uf2 (UF2 bootloader drag & drop) + <env>-dfu.zip (adafruit-nrfutil)
#               rp2040 -> <env>.uf2 (BOOTSEL drag & drop)
#               stm32  -> <env>.bin / <env>.hex (STM32CubeProgrammer / SWD)
#
# `build.sh all` builds every line; `build.sh <env> [<env> ...]` builds a subset.
